# CONTEXT.md — глоссарий (русский перевод)

Файл отвечает только на вопрос «что это слово означает в этом репозитории».

**Правило допуска**: новый термин добавляется, только если его используют два и более модуля и неоднозначность названия влияет на реализацию.

## Уровень протокола

- **wire-класс**: тип сериализуемого объекта клиентского протокола со стабильным `type_id`.
- **type_id**: числовой идентификатор wire-класса в реестре протокола.
- **args code**: код типа элемента в списке параметров; элементы массива обязаны объявляться через него.
- **конверт**: внешняя обёртка запроса/ответа (номер команды, идентификатор вызова, нагрузка).
- **проверка контракта**: сравнение формы ответа с таблицей контрактов перед отправкой.
- **заглушка (fallback)**: пустая оболочка допустимой формы для команды без обработчика.

## Сессия и состояние

- **ядро сессии**: серверное рабочее состояние вошедшего игрока.
- **квитанция**: запись, что запрос (хэш токена + main + sub + call_id) выполнен один раз, ответ воспроизводится повторно.
- **мировые часы**: единственный источник игрового времени, производный от реального UTC (значение HUD = секунды суток UTC × 24).
- **блок параметров игрока**: периодический снимок состояния (энергия/сытость/комфорт/удача + мировые часы).
- **блок профиля**: полный публичный профиль игрока (валюта, уровень, навыки, сезон).

## Геймплей

- **снасть (rig)**: сборка удилище — катушка — леска — крючок — наживка.
- **материализация**: создание из заводских подкомпонентов предметов с собственным GUID и прочностью.
- **мастерство**: долгосрочный показатель по способу ловли/типу удилища.
- **садок**: пространство для пойманной рыбы, отличное от рюкзака.
- **зона косяка**: ячейка косяка по мировым координатам.
- **клёв**: набор видов рыбы, клюющих на водоёме в данный период, и их веса.

## Эксплуатация

- **Control Deck**: админ-консоль в launcher с отдельной аутентификацией.
- **статическая библиотека**: поставляемые в пакете конфигурационные данные только для чтения, отдельно от базы игроков.
