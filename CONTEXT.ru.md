# CONTEXT.md — глоссарий

Файл отвечает только на вопрос «что это слово означает в этом репозитории». В нём нет деталей реализации, он не служит спецификацией или заметками.

**Правило допуска**: новый термин добавляется, только если его используют **два и более модуля** и неоднозначность названия влияет на реализацию.

## Уровень протокола

- **wire-класс**: тип сериализуемого объекта клиентского протокола со стабильным `type_id`. Обфусцированное имя класса в декомпиляции и есть он.
  _Избегать_: DTO, тело сообщения, структура. `DTO` означает только контейнер полей после десериализации на клиенте. Это другой уровень.
- **type_id**: числовой идентификатор wire-класса в реестре протокола. Он определяет, каким ридером клиент разбирает объект.
  _Избегать_: номер команды, opcode. Номер команды — это пара `main/sub`.
- **args code**: код типа, указывающий, что лежит в данной ячейке списка параметров. Элементы массива обязаны объявляться через него.
  _Избегать_: type_id, field op. `op` — это кодировка ширины или метка отдельного поля.
- **конверт**: внешняя обёртка запроса или ответа. Содержит номер команды, идентификатор вызова и полезную нагрузку.
  _Избегать_: пакет, кадр. Кадр — единица транспортного уровня.
- **проверка контракта**: сравнение формы ответа с таблицей контрактов команд перед отправкой. При несоответствии ответ не отправляется.
  _Избегать_: проверка параметров, проверка типов.
- **заглушка (fallback)**: пустая оболочка допустимой формы, возвращаемая, если у команды нет обработчика.
  _Избегать_: значение по умолчанию, деградация. Заглушка не является безопасным значением по умолчанию: если приведение типа на клиенте не удастся, возникнет цепочка сбоев.

## Сессия и состояние

- **ядро сессии**: серверное рабочее состояние вошедшего игрока. Включает соединение, кэш профиля и состояние текущей игровой механики.
  _Избегать_: соединение, сокет, объект пользователя.
- **квитанция**: запись о том, что один и тот же запрос (хэш токена + main + sub + call_id) выполняется один раз, а ответ воспроизводится повторно.
  _Избегать_: кэш, журнал транзакций.
- **мировые часы**: единственный источник игрового времени. Они вычисляются из реального UTC. Значение на HUD равно числу секунд текущих суток UTC × 24.
  _Избегать_: серверное время, локальное время, время погоды.
- **блок параметров игрока**: периодически отправляемый снимок состояния игрока (энергия, сытость, комфорт, удача + мировые часы).
  _Избегать_: полоски состояния, здоровье. Это не четыре независимые шкалы здоровья.
- **блок профиля**: полный публично видимый профиль игрока. Содержит валюту, уровень, навыки и сезонную информацию. Блок параметров игрока вложен в него.
  _Избегать_: объект игрока, данные аккаунта.

## Геймплей

- **снасть (rig)**: собираемая комбинация удилище — катушка — леска — крючок — наживка. Связи сборки хранит сервер и проецирует клиенту производные таблицы.
  _Избегать_: снаряжение, комплект.
- **материализация**: создание из заводских подкомпонентов (бланк удилища, кольца, рукоять и т. д.) экземпляров предметов с собственным GUID и прочностью.
  _Избегать_: инициализация, разворачивание, клонирование.
- **мастерство**: долгосрочный показатель, накапливаемый по способу ловли или типу удилища. Не совпадает с уровнем персонажа.
  _Избегать_: опыт, очки навыков, уровень.
- **садок**: пространство для пойманной рыбы. Отличается от рюкзака.
  _Избегать_: рюкзак, склад.
- **зона косяка**: ячейка косяка рыбы на карте, выделенная по мировым координатам. Один вид в одной зоне делит общий ритм появления.
  _Избегать_: точка ловли, район, водоём. Водоём — это вся карта, точка ловли — место, где можно стоять.
- **клёв (рыбный набор)**: набор видов рыбы, клюющих на водоёме в данный период времени, и их веса.
  _Избегать_: шанс выпадения, таблица вероятностей.

## Эксплуатация

- **Control Deck**: админ-консоль, встроенная в launcher, с отдельной аутентификацией.
  _Избегать_: бэкенд, страница admin. `cmd/admin` — это другая отладочная точка входа, не она.
- **статическая библиотека**: поставляемые в пакете конфигурационные данные только для чтения. Во время работы монтируется только для чтения и отделена от базы игроков.
  _Избегать_: конфигурация, каталог данных, seed-база. Seed — это инструмент, который генерирует статическую библиотеку.
