# Таблица официальных эффектов навыков дальности заброса (cast-skill-official-effects)

Источник: дословное извлечение из ресурсов локализации **клиента 4.0.25034**, а не самодельная калибровка.
Этот документ служит основанием для аудита `skill_cast_effect_def` (миграция 00060 + начальные данные `ensureCastSkillEffects`).

## Метод извлечения (воспроизводимый)

1. Ключи текстов навыков имеют вид `ability_<node_id>` (название) и `ability_<node_id>_<level>` (описание каждого уровня).
2. JSON-блоки на 16 языках находятся в `Game/rf4_x64_Data/resources.assets` (359 МБ). Блок упрощённого китайского начинается примерно со смещения `~289500774`, немецкий блок лежит в `~[284.9M, 289.5M)` (немецкие оригинальные названия нужны, чтобы выявлять ошибки китайского перевода, см. ниже).
3. Записи ищутся по байтовому шаблону `"ability_<id>":{"systemId":...}`, регулярным выражением извлекаются записи с иероглифами CJK. Всего 680 текстов навыков на упрощённом китайском.
4. Проверка ступеней уровней: для каждого узла последовательно выводится `ability_<id>_<n>`. Все они дают линейную лестницу +5% за уровень (без убывания и ступенек).

## Известные ограничения

- Деление традиционных катушек на **лёгкие/тяжёлые** (718/1008 и 721/1020) в `fopbhlmkcpe` одинаково — тип 4, различить по снаряжению нельзя. Для одной и той же ячейки gate берётся строка с наивысшим значением (две полностью изученные строки не суммируются).
- «Управляемость рыбы +3% за уровень» и «расход энергии при вываживании −5% за уровень» относятся к фазе вываживания, эта таблица их не засевает и не рассчитывает (вне области, для них нужен отдельный spec).
- Эффекты +10% за уровень для кормушек-садков (305/317, официальный текст «дальность заброса +10%») идут по отдельному каналу снаряжения для кормления, в этой версии не засеваются.

## Очистка самодельных строк по стороне рыбы

`skill_fish_effect_def` (00038, `source='local-sim'`/confidence 0.45, после нормализации общей группы `local-sim:shared-group`) выдавал узлам из таблицы выше самодельные эффекты клёва, противоречащие официальным текстам (например, 701 отображался как ecology_interest +3.5% за уровень). `ensureCastSkillEffects` на пути запуска, в производственном порядке (после ensure клёва), удаляет для всех узлов таблицы строки по стороне рыбы с `source LIKE 'local-sim%'`. Официальные и ручные строки, а также узлы, в официальных текстах которых есть смысл по стороне рыбы (например 301/502/504/506/508/510 — редкая рыба / количество улова), не затрагиваются.
