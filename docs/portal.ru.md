# Личный кабинет

`/portal/` на gateway даёт профиль персонажа, баланс и покупку членства за игровое золото. Сначала на том же устройстве нужно войти в игру и создать персонажа, страница использует правило шлюза, который определяет персонажа по исходному IP.

> **Граница идентичности:** `/portal/` подходит только для одиночной игры или доверенного использования на локальной машине. Не выставляйте порт входа напрямую в публичную сеть. Пользователи за одним NAT, прокси или выходным IP определяются как один и тот же персонаж и смогут обращаться к золоту этого персонажа и тратить его. Если нужен общий доступ нескольких людей, сначала подключите отдельную аутентификацию аккаунтов.

Членство использует только локальное игровое золото. Обычное, временное и постоянное членство используют один и тот же метод хранения основной линии. Неудачную покупку можно повторить для того же заказа, это исключает двойное списание. Статические ресурсы страницы поставляются вместе с сервисом, сторонний сервис изображений не нужен.
