# Выводы по перехвату протокола официального сервера (ремонт и замена деталей в мастерской)

Способ перехвата: `tools/frida/net_capture.py` (hook только для чтения внутри процесса клиента, сетевые данные не менялись).
Образцы: `logs/net_capture_official.jsonl`, `logs/net_capture_official2.jsonl`.
Инструмент декодирования: `go run ./tools/cmd/netdecode <jsonl> <cmd|call:N>`.

## 21/1 список мастерской (ответ)

Корневой массив с args code **144**, элемент `ookkpknacja`(505):

| Поле | Содержимое |
|---|---|
| f0 | GUID предмета |
| f1 | Целостность f32 (битовая форма, наблюдалось 0.9991~1.0) |
| f2 | Фиксированное **4** |
| f3 | `oinpmjophkh[]`: **typed_u32arr** (0x07 + имя типа), при отсутствии износа пусто |

> Обратите внимание: официальный сервер действительно использует typed_u32arr. Ранее мы отправляли имя типа "17", из-за чего приведение `kkeibjcmjnl -> oinpmjophkh[]` не удавалось. Нужно отправлять пустой typed-массив или то имя типа, которое использует официальный сервер.
