# Протокол и поведение заброса приманки из рогатки

## Цепочка команд

```text
13/4  взять рогатку
13/1  зарядить порцию прикормки, сервер выделяет дочерний экземпляр заряда и записывает ссылку на заряд в рогатку
13/5  бросить один выстрел: сервер расходует дочерний экземпляр заряда, записывает запись в книгу прикормки и возвращает 805
13/6  запрос полного снимка снасти
```

В слоте боеприпасов фактически расходуется дочерний экземпляр, выделенный командой 13/1, а не исходная стопка в рюкзаке.

## Поля ответа 805

805 / `lmbomkliaad` содержит дальность броска, процент разброса, блок позы, обновления экземпляров предметов, необязательный экземпляр брошенного предмета и массив удаления GUID.

В этом ответе нет полей мировых координат и направления. Клиент сам вычисляет вид полёта, а сервер управляет дальностью, разбросом и изменениями предметов.

## Поведение сервера

- Каждый выстрел расходует одну порцию из слота заряда и записывается в книгу прикормки.

- Ключ идемпотентности прикормки для 13/5 включает GUID рогатки, номер сессии и CallID.

- Дополнительный экземпляр брошенного предмета по умолчанию выключен, чтобы не дублировать летящую приманку, которую клиент рисует сам.

- Блок позы по умолчанию включён: клиент использует его для обновления глобального времени и позы игрока.


## Настраиваемые параметры

| Параметр | По умолчанию | Описание |
|---|---:|---|
| `handitem_throw_scatter` | 5.0 | Процент разброса в 805 |
| `handitem_throw_pose` | 1 | Отправлять ли блок позы |
| `handitem_throw_projectile` | 0 | Отправлять ли дополнительно экземпляр брошенного предмета |
| `handitem_throw_selfclean` | 0 | Попадает ли брошенный предмет одновременно в массив удаления |

## Известные ограничения

Нативный клиент сам формирует направление полёта комка прикормки по локальному состоянию прицеливания. В 805 нет передаваемых координат или направления, поэтому сервер не может исправить визуальное направление только средствами протокола. Текущая реализация гарантирует согласованность списания прикормки, записи в книге и проверки клёва.

## Регрессионное покрытие

- структура ответа 805 из шести полей;

- границы параметра разброса;

- выключенный по умолчанию дополнительный экземпляр брошенного предмета;

- связь f4/f5 при явном включении брошенного предмета.
