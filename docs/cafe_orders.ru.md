# Заказы кафе

Кафе отдельно создаёт заказы, которые сменяются по реальному времени. Требования составляются из водоёма, вида рыбы и публичных расценок. Редкие заказы появляются в небольшом числе и принимают только одну рыбу. Пропорциональная оценка — локальное правило, а не официальная формула. Сейчас охвачено 17 водоёмов с данными о расценках, для Медвежьего озера надёжного шаблона пока нет.

При сдаче заказа в одной транзакции проверяются и списываются подходящие рыбы, выплачивается серебро и сохраняется квитанция. Повторная сдача возвращает исходную квитанцию, награда не выдаётся повторно. Торговля наличной рыбой на рыбном рынке по-прежнему идёт через прежний вход.

Обновление использует миграцию 27: она только по названиям преобразует старые локальные миграции кафе 23 и 25 и не затрагивает миграции катушек основной линии 23–25 и состояния персонажа 26. Исторические заказы, расценки, квитанции и баланс игроков сохраняются.
