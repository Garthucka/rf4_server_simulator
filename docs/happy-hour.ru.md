# Счастливые часы

Право участия привязано к членству. Администратор в данных игрока ставит членство «Временный премиум» (с указанием срока окончания) или «Постоянное членство», и Счастливые часы включаются автоматически. У тех, у кого нет членства, права нет. Общий переключатель на странице правил клёва по-прежнему может приостановить бонус полностью.

Ежедневного ограничения по времени больше нет: пока члены клуба рыбачат онлайн, бонус действует всё время, без накопления и списания. Выход из сети, пауза и вываживание на квоту не влияют. Несколько сессий одного персонажа делят одно онлайн-состояние, бонус в один момент получает только одна сессия. Временное членство перестаёт действовать сразу после окончания срока. Постоянное членство без ограничения по времени.

При включённом бонусе базовый опыт улова увеличивается дополнительно на 50%, итоговая вероятность принятия наживки относительно повышается на 10%, вероятность срабатывания роста мастерства относительно повышается на 25% с потолком 95%. Итоговая вероятность принятия для малоинтересной наживки не превышает 10%, запрещённая наживка по-прежнему исключается. Предел постоянного мастерства и размер одного прироста не меняются. Всё перечисленное — значения локальной игры.

Состояние Счастливых часов на странице профиля тоже следует за членством. Для временного членства показывается «Идёт» с обратным отсчётом по оставшемуся времени членства. Для постоянного показывается «Готово» без обратного отсчёта (в клиенте нет состояния «без ограничения по времени», у состояния 3 есть только тексты с оставшимися минутами и «осталось меньше минуты»). Тем, у кого нет членства, показывается, что нужен премиум. Если общий переключатель выключен, «Идёт» больше не показывается. Подробнее см. `specs/changes/happy-hour-membership/spec.md`.

Право участия сохраняется вместе с исходной рыбой в момент поклёвки. Отложенное получение рыбы, повтор расчёта при сбое или переподключение используют исходное право. Дополнительный опыт считается от базового опыта улова и записывается в ту же квитанцию расчёта. Разложение опыта в клиенте 4.0.25034 использует существующий kind57. Страница администратора показывает срок окончания членства и оставшееся время. Обновление базы данных не меняет существующие уровни, опыт, золото и очки навыков.

Функция опирается на атомарный расчёт улова, право сохраняется вместе со снимком рыбалки. Серверные тесты и тесты миграций покрывают право участия и идемпотентность. Значок активности в игре и поведение в реальном клиенте ещё требуют приёмки в работе.
