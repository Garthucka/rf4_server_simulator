# rf4_server_simulator

**Open-source локальный серверный эмулятор рыболовной игры, который совместно поддерживает OpenFisherCommunity.**

Он позволяет на своём компьютере пройти весь путь рыбака: собрать удочку, выбрать приманку, сделать заброс и вываживание, а затем заняться прокачкой, крафтом, заданиями и коллекциями. Проект рассчитан на локальную игру, обучение, исследования и работу сообщества. Его также можно развернуть в доверенной локальной сети.

> **Проект бесплатный, с открытым кодом, разработка продолжается.** Мейнтейнеры не берут денег, не продают сервер, сб��рки и услуги установки и не принимают пополнения, пожертвования или спонсорскую помощь.
>
> Это эмулятор сервера, самой игры в нём нет. Сейчас поддерживается клиент **4.0.25034**.

Полный перевод README: см. оригинал README.md (китайский) и README.en.md (английский). Этот файл — русская версия.

## Быстрый старт (Windows)

1. Скачайте из Releases пакет, имя которого заканчивается на `windows-amd64.zip`, и распакуйте его целиком (не `Source code`).
2. Подготовьте клиент 4.0.25034 и по файлу быстрого старта из пакета настройте доверие к локальному сертификату и hosts (docs/deploy.md).
3. Запустите `启动服务器.cmd` или `bin\launcher.exe`, откройте http://127.0.0.1:9500/ и дождитесь готовности сервиса.
4. В центре управления сохраните путь к `rf4_x64.exe` и нажмите «Запустить игру».

## Docker

```sh
docker compose -f docker/compose.yaml up -d --build --wait
```

Админка в режиме Docker: `http://127.0.0.1:8080/`. Клиент настраивается и запускается отдельно.
